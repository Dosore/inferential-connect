Connect or reconnect QuickBooks Online

This private integration is for Inferential Limited's own company. It uses assisted local setup, not a public sign-up service. Only a person with appropriate company and developer-app permissions may perform these steps.

Production onboarding

  1. Complete Intuit's production-access requirements for the developer app. Production credentials must be unlocked before a live company can be connected.
  2. Review the privacy policy, account data-use settings and company authority before using live information.
  3. Use Intuit's OAuth 2.0 Playground for the assisted authorisation flow where available. In the app's production settings, register the exact callback specified by the Playground. The published Playground callback is https://developer.intuit.com/v2/OAuth2Playground/RedirectUrl. Confirm the current value in Intuit before saving.
  4. Use the production app credentials and the QuickBooks Accounting scope. Sign in on Intuit's own pages and select Inferential Limited's correct live company. Follow Intuit's authorisation-code and token-exchange steps. This website never collects the credentials or tokens.
  5. Store production credentials, refresh token and company identifier through the approved local setup. Use a separate production token file and MCP connection so the sandbox remains isolated. Never paste tokens into chat or email.
  6. Verify the connected company with a read-only request before requesting record changes.

Reconnection

If the connection expires or is revoked, an authorised operator repeats the appropriate Intuit authorisation process and updates only the matching company's local connection. Do not reuse sandbox tokens for production.

Contact Denisosore@outlook.com for assisted operation. This page does not itself initiate or exchange OAuth credentials. Availability of Intuit's Playground and acceptance of this private assisted workflow are subject to Intuit's current requirements; these instructions do not guarantee production approval.
